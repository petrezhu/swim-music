# swim-music 安装包

本仓库只发布「游泳耳机秘书 swim-music」的 Nuitka 便携包与在线更新清单，不放源码。

- 下载：见 [Releases](https://github.com/petrezhu/swim-music/releases)
- 每个 Release 包含对应平台的 `swim-music-<platform>-portable.zip` 与 `manifest-<platform>.json`
- 应用内「帮助 → 检查更新」会优先走 petrezhu.cn，失败时依次回退 Gitee / 本仓库 Release

安装包 sha256 见 Release 说明或对应的 manifest 文件。
